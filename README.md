# Турбо ПВЗ → черновик закрытия (Chrome + API)

Chrome-расширение собирает цифры закрытия смены с [turbo-pvz.ozon.ru](https://turbo-pvz.ozon.ru) и отправляет черновик на API. В чат пункта пишет только Telegram-бот после подтверждения человека.

## Структура

```
extension/     — Chrome Extension (Manifest V3)
api/           — минимальный HTTP API черновиков (Python stdlib)
```

## Быстрый старт

### 1. API черновиков

```powershell
cd api
copy .env.example .env
# при желании поменяйте EXTENSION_API_TOKEN в .env
python server.py
```

API слушает все сетевые интерфейсы, порт `8787`. На компьютере с ботом расширение ходит на `http://127.0.0.1:8787`. На других пунктах в Base URL вставляют адрес, который сервер печатает при запуске. Токен по умолчанию: `dev-extension-token-change-me`.

### 2. Расширение (Load unpacked)

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное расширение** → выберите папку `extension`
4. Клик по иконке расширения открывает окно поверх сайта
5. В настройках окна укажите URL API и тот же токен, что в `.env`

### 3. Тест на реальном Турбо ПВЗ

1. Войдите на `https://turbo-pvz.ozon.ru` в нужный ПП
2. Убедитесь, что в шапке виден пункт вида `ПП_1125`
3. В окне расширения должен отобразиться номер ПП
4. Нажмите **Собрать закрытие** — расширение обойдёт выдачу, остатки, тару, завершённые перевозки и засылы
5. Проверьте превью и предупреждения
6. При нескольких перевозках за день — выберите нужную
7. **Отправить боту** → `POST /api/drafts`
8. Проверка: `GET http://127.0.0.1:8787/api/drafts/1125` с заголовком `Authorization: Bearer <token>`

## Контракт черновика

См. `extension/shared/draft-schema.md` и ответ API.

## Важно

- ПП всегда читается из шапки сайта, не из «привязки ПК»
- Токен Telegram-бота в расширение не кладётся
- Селекторы DOM — в `extension/content/selectors.js` (сайт SPA, вёрстка может меняться)
